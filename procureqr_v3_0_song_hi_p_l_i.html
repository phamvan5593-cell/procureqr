Kết Nối Google Sheets (Cơ Sở Dữ Liệu Miễn Phí)

Nhập đường link Web App của **Google Apps Script** để toàn bộ Đề xuất PR, Đơn hàng PO, Tồn kho và Số Hóa đơn VAT tự động đồng bộ 2 chiều về File Trang tính Google của Công ty Song Hiệp Lợi.

Hướng dẫn nhanh 3 bước lấy mã API Google Sheets:

  1. Vào Google Sheets công ty ➔ Chọn **Tiện ích mở rộng** ➔ **Apps Script**.
  2. Dán đoạn mã xử lý API backend và bấm **Triển khai** ➔ **Dưới dạng Ứng dụng Web**.
  3. Chọn quyền truy cập **"Bất kỳ ai (Anyone)"** rồi copy đường link `https://script.google.com/.../exec` dán vào ô trên.
